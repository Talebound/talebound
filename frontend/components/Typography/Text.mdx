# Text

Renders a span component. Expects a string as a child.

## Default paragraph

This is how paragraph looks with default settings:

<div className="sb-unstyled">
  <Text>
    Lorem ipsum dolor sit amet, consectetur adipiscing elit. Donec euismod, nisl eget ultricies
    aliquam, nunc, nec aliquet nunc nisl eget ultricies aliquam, nunc, nec aliquet nunc, nec aliquet
    nunc nisl eget ultricies aliquam.
  </Text>
  <Text>
    Donec euismod, nisl eget ultricies aliquam, nunc, nec aliquet nunc nisl eget ultricies aliquam,
    nunc, nec aliquet nunc, nec aliquet nunc nisl eget ultricies aliquam. Lorem ipsum dolor sit
    amet, consectetur adipiscing elit.
  </Text>
</div>

## Sizes

The component supports the following sizes:

XS, SM, MD, LG

<div className="sb-unstyled">
  <Col gap="md">
    <Text size="xs">Extra Small</Text>
    <Text size="sm">Small</Text>
    <Text size="md">Medium</Text>
    <Text size="lg">Large</Text>
  </Col>
</div>

## Colors

The component supports the following colors:

Primary, secondary, tertiary, success, danger, info, warning, white, black

## Weights

The component supports the following weights:

Regular, medium, semibold, bold

<div className="sb-unstyled">
  <Col gap="md">
    <Text weight="regular">Regular</Text>

  </Col>
</div>

## Bold and Italic shortcuts

Bold has a shortcut b

Italic has a shortcut i
